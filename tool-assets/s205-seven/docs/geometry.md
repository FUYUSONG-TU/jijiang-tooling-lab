# 七类刀具几何与坐标规范

本轮新增7种工具，各1份GLB；与原35°菱形车刀共存，既没有改动35° GLB，也没有把它的3个R角统计为3把刀。新刀具为有独立刃部、柄/杆、适用夹紧结构的参数化教学资产，不是厂家数字孪生。

## 单位、安装点与切削点

- Blender源场景：1设计坐标单位=1mm，unit_settings.scale_length=0.001，显示毫米。
- GLB：导出前把网格坐标转为米，文件遵循glTF2的Y-up；不存在外部纹理或外部Buffer URI。
- lib/tools.js返回的根节点：毫米、右手Z-up。唯一的内部换算为`Rx(+90°) × S(1000)`。
- 模型后端截面中心是安装原点(0,0,0)。+Y朝向后端，刀具前端在负Y；+X为宽度，+Z为刀片顶面或圆截面的竖向。
- 每把刀的cuttingReferencePoint由真实网格上的最近表面点求得，可能是前刃中心、端部切削角或钻尖，不能用模型中心代替。
- 圆柱工具axisOrigin与axisDirection单独记录。立铣刀刃角在轴线之外，axialGaugePoint是轴线上前端量规平面的数学点，不宣称它落在实体表面上。
- 所有整体包围盒包括资产自身的刀杆/柄、刃部、刀座、夹紧和螺丝，不包括工位夹头或动力头。

所有矩阵为Three.js列主序。模型局部轴不等于机床编程轴，本包不指定S205控制器通道、轴名或运动正负方向。

## 实体结构

1. **外圆切槽刀**：10mm方杆轮廓、收窄刀头、真实座腔及垫座、2mm前刃、底部收窄和约0.35mm前部让位、顶面断屑凹槽、台阶上压块、同轴孔及真实六角驱动螺丝。
2. **切断刀**：方杆安装体、开槽夹持接口、1.6mm独立薄刀板、1.5mm切刃刀片、前部让位和断屑槽、两颗侧压螺丝。刀板和安装方杆分开，不能把厚安装体当作切断刃。
3. **外螺纹刀**：成形刀头、三角刀座/垫座、60°局部牙型刀片、圆角、实体三角凹面及中心支承岛、中心孔与螺丝。没有指定螺距，未宣称全牙型或特定ISO刀片型号。
4. **中心钻**：Ø6柄、Ø2导向段、60°中心锥面、118°导向钻尖及两条真实容屑槽。采用单端通用教学构型，非特定型号尺寸。
5. **麻花钻**：Ø4柄、两条30°螺旋凹槽、连续芯部、窄刃带和118°尖部。螺旋槽是闭合实体边界的凹入，不是装饰线；横刃和后刀面并非精密磨削复刻。
6. **内孔镗杆**：Ø8圆柄、Ø5.6缩颈、前部磨削平面、偏置小型可转位刀片、垫座与紧固孔。借鉴内孔图的圆柄和缩颈，不冒称照片中的MTR整体刀是同一产品。
7. **整体硬质合金立铣刀**：Ø6柄、4条35°螺旋槽、端部排屑/后隙形体、连续实体芯部。柄和刃部的网格划分用于材料与检查，二者属于同一整体刀具，不是刀座。端部中心切削能力未核实，不宣称可以中心下钻。

每个JSON的parameters是这把资产的演示设计输入，overallDimensions/boundingBox来自实际成品网格，triangleCount来自导出GLB。实际总体长度不一定等于直柄长度，不能混用。

## 工位与刀具分离

工具GLB只包含自身部件；页面生成的U形排刀座、圆柄夹头/夹套及条件动力头属于工位夹具。工位夹具不是这些独立GLB的一部分，也未被算为新增刀具。夹持面、部件接合端面和支承座面可有意接触。

图中不能确定的螺纹、垫座背面、压紧力、制造公差、后角及涂层牌号均为未验证或未精确建模项。本包不能用于生产加工、刀具订货尺寸或机床安全认证。
