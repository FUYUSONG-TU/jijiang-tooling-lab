# 参考资料与证据范围

本轮逐张查看了项目已有的references/tooling/1-照片-1.jpg、3-照片-3.jpg及5-照片-5.jpg，并复用既有reference-analysis.json的文字识别结果。

- 第1张：内孔刀系列的圆柄、缩颈与前端刃形。图中MTR/MUR等代号不能直接解释成已验证产品规格，本轮镗杆不是这些具体产品的复刻。
- 第3张：通用小型CNC排刀示意，含G/H/J外圆类别、F内径与K钻孔类别及实拍刀座。F/G/H/J/K是图中刀具类别/章节的标记，不是已验证工位号。它不是可核验的津上S205厂家工位图，不能确认实际刀号、间距、轴配置或动力选配。
- 第5张：外圆刀头、刀片、上压结构和切槽结构的外观参考；不能从透视图推算尺寸或混淆标签角度。
- 项目没有可用的S205制造商尺寸图、选配清单或原生微信渲染工程。本轮未把通用几何默认值包装成厂家资料。

中心钻、麻花钻及立铣刀的直径、螺旋角、刃数和钻尖角是明确记录的教学设计参数。刀具型式有真实几何，但不宣称尺寸/精密刃磨与某厂家产品一致。

原始参考图片保留在原位置，未修改；新增可下载包只包含来源记录，不再分发未确认授权范围的照片。各来源哈希记录于reports/reference-provenance.json。
