# 机匠学院 · 35°菱形外圆刀结构样板

本轮仅一把刀：`JJ-OD35-SAMPLE-001`。R0.2 / R0.4 / R0.8 为同一刀具的演示鼻圆配置，不是扩展其他刀具。原 `/workspace/g01-demo`、`/workspace/g01-swiss-demo` 未修改。

## 打开

已运行 `http://localhost:8767/`。地址需在当前云环境浏览器打开，或转发8767端口后访问；其他电脑的localhost不会指向本环境。

重启：`python -m http.server 8767 --directory /workspace/tooling-sample`。
页面需联网加载 Three.js；模型、参数和参考图片均由本地服务提供。不要直接用file://打开。

## 交付文件

- `models/tool35-r0.4.glb`：默认样板，PBR材质、5个独立实体部件。
- `models/tool35-r0.4.blend`：对应Blender源场景。
- `build_tool.py`：完整Python参数化建模源代码。
- `models/tool35-r0.4.json`：独立参数、数据来源和待确认项。
- `reference-analysis.json`：5张图片逐项记录，其中内孔图9项、外圆图16格；第三第四张为重复排刀图。图中型号文字仅转录，不擅自解释为已核实尺寸。
- `references/tooling/`：本次5张原始附件的副本，及明确标注来源区域的样板裁切。原先工作区没有用户指定的参考目录，从附件目录找到原图后复制到独立样板目录，未用生成图替代。
- `models/quality-r*.json`：Blender网格与所选装配表面的检查记录。
- `verification.json`：带断言的GLB加载、刀尖坐标、显隐、分解、触摸交互验证。
- `screenshots/iso.png`、`top.png`、`front.png`、`side.png`：4个方向的原图/模型并排截图，另有分解与手机截图。

## 建模依据与边界

依据第5张图第二排第四格“35度菱形刀”。可见细长菱形片、中心螺丝、斜切银灰刀头和刀杆。只确认任务及图片标签给出的35°，不由透视图计算尺寸，也没有识别到可核实的制造商型号。

刀片：解析菱形，理论长对角线20mm，短对角线=20×tan(17.5°)，四角相切圆弧；厚度2.6mm、中心孔2.24mm均为演示默认。中心孔、沉孔、六瓣驱动凹槽和刀座均为实体几何。没有猜测专有断屑槽。

刀杆：10×10mm截面，模型Y=0到65mm为演示后部刀杆长度；前部斜切刀头向负Y延伸，因此整个刀杆长度大于65mm。参数holderLength由真实刀杆网格在Y轴上的包围范围计算，后部基准长度65mm另存rearShankDatumLength，避免把后部长度误当全长。刀杆主体是单个成形轮廓挤出与真实刀座布尔加工，不是几个方块拼凑。

参考图看不清的刀座底面、垫座、背面、沉孔、驱动型式、盲孔内部均为演示重建。螺纹没有被假装精确还原；螺丝以轴体与真实凹槽头部展示。PBR颜色是视觉区分，不代表实际牌号或涂层。

刀尖夹角35°、局部刀片平面旋转−18°、主偏角null是三个独立值。手向与机床安装尚未确定。GLB按米制导出；浏览器统一乘1000以毫米展示，并恢复Blender的局部Z向上坐标，坐标轴不表示机床轴定义。

`cuttingTipPosition`取自倒角后的真实网格顶点；`nominalNoseArcApex`保存未作刃口倒角的设计圆弧点；`virtualSharpTipPosition`保存理论尖角。三者分开，不能将理论尖角标成实体接触点。

## 检查结果与限制

Blender对三档鼻圆的5个部件均检查到0非流形边、正的有向体积和有限法线。所选刀杆/刀片、刀杆/螺丝头、垫座/螺丝头、刀片/螺丝头、刀片/螺丝轴表面BVH求交为0。刀座底面Z=−2.2与垫座底面贴合，垫座顶面Z=−1.6与刀片底面贴合，共面接触为装配设计，不是误穿透。

以上为网格及选定表面检查，不是所有零件的CAD实体容差认证；垫座前端的少量悬伸、隐藏夹紧细节也需要尺寸图复核。不能证明该演示座体承载合理或能实际制造。

Chromium加载实际GLB并检查三档鼻圆；刀尖标记与导出网格顶点偏差小于1e−4mm。已检查部件显隐、分解沿局部Z移动7mm、手机390px无横向溢出，以及通过CDP发送真实触摸事件后视角发生变化。桌面4个视图均已截图检查。

手机默认轻量预览材质，保留实体结构和金属高光；可关闭以查看PBR材质。该开关不改变GLB文件。静止时按需绘制，降低持续GPU占用。云端Chromium移动视口不等于真机；活动旋转实测数据写入verification.json，不承诺所有手机的帧率或将静态按需绘制次数当作旋转帧率。

## 再生成

安装环境已有Blender 4.3.2。执行：

```
blender -b --python /workspace/tooling-sample/build_tool.py -- --radius 0.4
```

可选半径0.1至0.8；预览菜单预置0.2/0.4/0.8。可修改脚本中的演示规格，但必须同步核验刀座、孔、紧固结构及参数记录。

开发检查（使用当前环境已有Playwright与/usr/bin/chromium）：

```
node /workspace/tooling-sample/check.cjs
node /workspace/tooling-sample/verify.cjs
```
